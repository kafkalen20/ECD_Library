# design/ — 큰 기능 설계 문서 (살아있는 문서)

큰 기능·구조 변경을 **구현 전에** 설계하는 문서 + 목업.
- **project/** = "현재 이렇게 동작한다"(설명) / **design/** = "앞으로 이렇게 만들자"(제안)
- **decisions/** = 짧은 결정 1개(ADR) / **design/** = 그 결정을 포함한 전체 설계 스펙

`_templates/design.md` 복사. 파일명 `<기능명>.md`.
`status`로 상태 관리(초안 → 리뷰중 → 확정 → 구현완료 → 폐기).
- 확정된 핵심 결정은 `decisions/`로 ADR 승격 가능.
- 목업(html 등)은 문서 옆에 두거나 `design/mockup/`에.
- 구현 완료·폐기된 설계는 `status`만 갱신(삭제하지 않음 — 나중에 "왜 이렇게 갔나" 참고).
