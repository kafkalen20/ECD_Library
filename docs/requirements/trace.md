# 요구사항 추적표

> 요구 하나 = 한 줄. 상태: `요청` → `분석` → `개발` → `시험` → `반영` (또는 `보류`·`취소`).
> 칸이 길어지면 링크로. 번호는 커밋·PR 제목·시험 이름에도 쓴다 (`requirements/README.md`).
> 표가 실제와 어긋나 보이면 `guides/req-trace.md` 절차로 다시 맞춘다.
