# delivery/ — 사람·외부에 보내는 문서 (전달 문서)

협력사·고객·다른 담당자에게 **보내는** 문서·메일 초안·수정 요청을 둔다.
(세션을 이어받을 AI·동료용 작업 인계는 `handoff/` — 섞지 않는다.)

`_templates/delivery.md` 복사. 파일명 `YYYY-MM-DD-받는곳-주제.md` (예: `2026-10-30-협력사A-오픈범위-안내.md`)

## 규칙 (check_docs.py 가 검사)
- `to:`(받는 사람) 와 **`## 가정한 것`** 필수 — 비었거나 양식 예시(`<예: ...>`·`<...>`)가 그대로면 오류. 가정이 없으면 "없음"이라고 쓴다.
- AI는 **초안까지만.** 사람이 `## 가정한 것`을 확인하고 발송한 뒤 `status: 발송완료`.
- 일정·범위·담당 값은 옮겨 적지 말고 `project/schedule-scope.md` 와 대조·링크.
