# handoff/ — 세션 간 작업 인계 (임시)

**진행 중인** 작업을 다른 세션·다른 사람·다른 AI가 이어받게 하는 임시 문서.
(예: Claude 세션이 끊겼는데 Codex가 이어서, 또는 내일 다른 개발자가 이어서.)
**사람·외부에 보내는 문서는 여기 말고 `delivery/`.** 완료·30일 방치 인계는 `check_docs.py`가 경고한다.

작업이 **끝나면 삭제하거나 `_archive/`로** 옮긴다(남아있으면 "진행 중"으로 오인).
완료된 지식은 여기 두지 말고 decisions/issues/guides/project 로 정리한다.

`_templates/handoff.md` 복사. 파일명 `<작업명>.md` (예: `global-search-refactor.md`)

## 담을 내용 (인계에 꼭 필요한 것만)
- **지금까지 한 것** — 완료된 부분
- **남은 것 / 다음 스텝** — 이어서 할 일
- **주의점 / 함정** — 모르면 삽질할 것
- **관련** — 브랜치·PR·이슈·관련 파일 경로
- **현재 상태** — 어디까지 동작하는지, 테스트 상황
