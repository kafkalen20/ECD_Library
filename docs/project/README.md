# project/ — 프로젝트 지식 (살아있는 문서, 통합)

프로젝트 구조 + 모듈 개요 + 고객사 특이사항을 여기 한곳에 둔다.
(폴더를 적게 유지하기 위한 통합. 문서가 많아지면 나중에 modules/·customers/로 분리 가능.)

## 무엇을 담나
- **프로젝트 구조·규칙**: Repository 구조·Odoo 버전·의존성·코딩/네이밍/커밋 규칙
- **모듈 개요(compass)**: 큰 모듈당 1파일 (`_templates/project.md` 복사, 25~35줄·4섹션)
- **고객사 특이사항**: 업무 규칙·연동 방식·특수 로직·주의점 (⚠️ 민감정보 X — 방법/위치만)

## 권장 파일
- `overview.md` — 프로젝트 한눈에
- `modules.md` — 모듈 지도 (모듈별 역할 한 줄) / 큰 모듈은 `module-<이름>.md` compass
- `conventions.md` — 코딩·네이밍·커밋·브랜치 규칙
- `customer-<주제>.md` — 고객사 특이 업무규칙 (필요 시)

owner를 두고, 코드가 바뀌면 같이 갱신한다.
